# Поиск новостей по Rust

## Источники (по приоритету)
1. https://blog.rust-lang.org — релизы и официальные анонсы.
2. https://blog.rust-lang.org/inside-rust/ — новости команд разработки языка.
3. https://this-week-in-rust.org — еженедельный дайджест (новый выпуск обычно по средам).
4. GitHub releases ключевых проектов: rust-lang/rust, rust-lang/cargo, tokio-rs/tokio,
   tokio-rs/axum, serde-rs/serde, launchbadge/sqlx, bevyengine/bevy.
5. https://rustsec.org/advisories/ — уязвимости в крейтах.
6. https://www.reddit.com/r/rust/ — топ за сутки, только как сигнал: проверяй по первоисточнику.

## Что важно
- Новые версии Rust (stable/beta), стабилизация фич, изменения edition.
- Крупные релизы экосистемы (tokio, axum, serde, sqlx, bevy и т. п.).
- Уязвимости RustSec в популярных крейтах — всегда в приоритете.
- Статьи и доклады с практическими выводами, опыт Rust в продакшене.

## Что пропускаем
- Мелкие патч-релизы без заметных изменений.
- Анонсы «я написал ещё один …» без практической ценности.
- Новости старше 3 дней.
