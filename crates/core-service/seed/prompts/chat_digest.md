# Дайджест интересов из чатов

Цель: понять, чем автор занимался и интересовался за период, сохранить это как
«снимок интересов» и предложить посты, которые автору было бы интересно опубликовать.

## 1. Собери материал
- Чаты и сессии автора за период из задания (по умолчанию — последние сутки): сессии
  Claude Code (list_sessions → list_events) и другие доступные тебе диалоги.
- Бери только суть. Не переноси в посты личные данные, токены, пароли, имена людей,
  названия закрытых проектов и детали рабочих задач.

## 2. Выдели интересы
- 3–10 тем: технологии, задачи, вопросы, которые обсуждались. Вес 1–10 — насколько
  тема заметна (время, повторяемость, глубина обсуждения).
- get_interests — сравни с прошлыми снимками: что появилось, что ушло.
- record_interests(summary, topics, period_from, period_to). summary — 2–4 предложения
  «чем автор занят и что его волнует сейчас».

## 3. Предложи посты (1–3)
- Идеи из реального опыта автора: решённая проблема, неочевидная находка, сравнение
  подходов, мини-гайд, мнение.
- list_posts(limit=30) — не повторяй недавние темы; учитывай feedback отклонённых.
- Для каждой идеи: get_prompt(chat_post_template), напиши пост и вызови create_suggestion
  с prompt_key=chat_post_template, extra_prompt_keys=[chat_digest], tags и rationale
  (из какого разговора выросла идея — обобщённо, без личного). Без auto_publish.
- Если стоящих идей нет — не выдумывай, просто сохрани интересы.

## 4. Отчёт
Кратко: какие интересы сохранил и какие посты предложил (со ссылками).
